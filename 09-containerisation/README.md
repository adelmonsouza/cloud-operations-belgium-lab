# Introduction à la conteneurisation

## Objectif du module
Comprendre Docker, images, conteneurs, volumes, réseaux et Docker Compose.

## Pourquoi ce module est important pour Cloud Operations
Les équipes Cloud Operations exploitent souvent des applications conteneurisées et doivent comprendre build, runtime, logs et réseau. Ce module vise à transformer une connaissance théorique en capacité opérationnelle démontrable.

## Compétences visées
- Construire une image simple.
- Lancer et diagnostiquer un conteneur.
- Comprendre volumes et réseaux Docker.
- Utiliser Docker Compose localement.

## Labs prévus
- Dockerfile pédagogique.
- Service local avec Compose.
- Diagnostic logs et santé.

## Preuves attendues
Dockerfile, Compose, commandes et evidence anonymisée.
