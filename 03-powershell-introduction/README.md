# Introduction à PowerShell

## Objectif du module
Apprendre les bases de PowerShell pour automatiser l'administration Windows.

## Pourquoi ce module est important pour Cloud Operations
PowerShell permet d'automatiser inventaires, diagnostics, actions répétitives et administration Microsoft. Ce module vise à transformer une connaissance théorique en capacité opérationnelle démontrable.

## Compétences visées
- Utiliser cmdlets, pipeline et objets.
- Lire et écrire des scripts simples.
- Gérer les erreurs explicitement.
- Produire des sorties exploitables.

## Labs prévus
- Inventaire système non sensible.
- Vérification de services.
- Script de rapport local.

## Preuves attendues
Scripts, sorties anonymisées et notes de validation.
