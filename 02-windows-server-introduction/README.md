# Introduction à Windows Server

## Objectif du module
Découvrir les rôles, services et principes d'administration de Windows Server.

## Pourquoi ce module est important pour Cloud Operations
De nombreuses organisations belges utilisent Windows Server pour identité, fichiers, DNS, DHCP et applications internes. Ce module vise à transformer une connaissance théorique en capacité opérationnelle démontrable.

## Compétences visées
- Identifier les rôles serveur.
- Comprendre Server Manager et services Windows.
- Documenter une installation pédagogique.
- Appliquer une checklist de base.

## Labs prévus
- Installation ou simulation Windows Server.
- Inventaire des rôles et services.
- Checklist post-installation.

## Preuves attendues
Notes, checklists, captures anonymisées et commandes non sensibles.
