# Laboratoire final jury

## Titre

Plateforme Cloud Operations pour une PME belge fictive

## Contexte fictif

Une PME belge souhaite moderniser son infrastructure avec une approche hybride, sécurisée et supervisée. Elle a besoin d'une base réseau claire, de serveurs Windows/Linux, d'automatisation, d'un environnement cloud Azure, d'une supervision, d'une stratégie de sécurité opérationnelle et d'une documentation compréhensible par une équipe IT junior.

## Objectif

Intégrer les compétences du programme dans un dossier final défendable devant jury.

## Périmètre

Réseau, Windows Server, PowerShell, Linux, Bash, Azure, Microsoft 365 si possible, AWS conceptuel ou mini-lab, Docker, Terraform, VMware conceptuel, observabilité, sécurité, gestion d'incidents et défense orale.

## Preuves attendues

Architecture, procédures, scripts non destructifs, runbooks, evidence anonymisée, incident fictif, RCA et support de défense.

## Statut initial

Squelette créé. Contenu à compléter progressivement avec les modules.
