# Terraform

## Objectif du module
Comprendre l'infrastructure as code avec Terraform, en environnement pédagogique et public-safe.

## Pourquoi ce module est important pour Cloud Operations
Terraform permet de décrire, relire, versionner et automatiser l'infrastructure. Ce module vise à transformer une connaissance théorique en capacité opérationnelle démontrable.

## Compétences visées
- Comprendre providers, resources, variables, outputs et state.
- Lire un plan Terraform.
- Structurer des modules simples.
- Appliquer les règles de sécurité IaC.

## Labs prévus
- Exemple local ou cloud fictif.
- Module réutilisable pédagogique.
- Analyse d'un plan anonymisé.

## Preuves attendues
Fichiers `.tf` sans secrets, plans anonymisés et notes de sécurité.
