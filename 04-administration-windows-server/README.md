# Administration Windows Server

## Objectif du module
Administrer les services Windows Server essentiels : Active Directory, DNS, DHCP et GPO.

## Pourquoi ce module est important pour Cloud Operations
L'identité, la résolution de noms et les politiques de configuration restent centrales dans les environnements hybrides. Ce module vise à transformer une connaissance théorique en capacité opérationnelle démontrable.

## Compétences visées
- Comprendre AD DS et objets d'annuaire.
- Administrer DNS et DHCP.
- Comprendre l'usage des GPO.
- Documenter des procédures d'exploitation.

## Labs prévus
- Domaine fictif.
- DNS/DHCP pédagogique.
- GPO de sécurité de base.

## Preuves attendues
Schémas, checklists, captures anonymisées et procédures.
