# Portfolio

Ce dossier transforme les apprentissages du laboratoire en éléments utilisables pour GitHub, CV, LinkedIn, entretiens, stage et défense devant jury.

Les case studies sont des squelettes professionnels. Ils ne doivent pas inventer une expérience professionnelle réelle : ils doivent décrire des labs personnels, scénarios fictifs et preuves pédagogiques.

## Utilisation

- Relier chaque case study à un ou plusieurs labs.
- Utiliser des formulations honnêtes : "lab personnel", "scénario fictif", "préparation AZ-104".
- Ne jamais inclure de données employeur, client ou système interne.
- Mettre à jour les bullet points CV quand une preuve réelle est disponible dans le dépôt.
