# Case study - Terraform et Infrastructure as Code

## Statut
Squelette à compléter après les premiers exemples Terraform.

## Contexte
Exemple pédagogique d'infrastructure as code pour décrire une architecture simple et contrôlée.

## Objectif
Montrer la compréhension des plans, variables, modules, state et règles de sécurité IaC.

## Structure
- Besoin fictif.
- Architecture cible.
- Structure Terraform.
- Validation avec `terraform plan`.
- Gestion des secrets.
- Limites.
- Evidence GitHub.

## Limite honnête
Ne jamais inclure state réel, credentials, `.tfvars` sensible ou ressources cloud non anonymisées.
