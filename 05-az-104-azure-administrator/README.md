# AZ-104 - Azure Administrator

## Objectif du module
Préparer les domaines pratiques de la certification Microsoft Azure Administrator AZ-104.

## Pourquoi ce module est important pour Cloud Operations
Azure est central pour les rôles Cloud Operations en Belgique : identité, compute, réseau, stockage, supervision et gouvernance. Ce module vise à transformer une connaissance théorique en capacité opérationnelle démontrable.

## Compétences visées
- Administrer identités et accès.
- Gérer ressources, compute, stockage et réseau.
- Utiliser Azure Monitor et Log Analytics.
- Documenter coûts, risques et validations.

## Labs prévus
- Resource groups pédagogiques.
- VM ou scénario compute fictif.
- Requêtes KQL simples.
- Checklist sécurité Azure.

## Preuves attendues
Notes AZ-104, captures anonymisées, commandes Azure CLI sans credentials, KQL et rapports.
