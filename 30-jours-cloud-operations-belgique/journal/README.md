# Journal du défi

Ce dossier contient les journaux quotidiens du défi `30 Jours Cloud Operations Belgique`.

Chaque entrée doit rester courte, factuelle et public-safe :

- objectif du jour ;
- action réalisée ;
- preuve ajoutée ;
- question d'entretien ;
- prochaine action.

Ne jamais inclure de données employeur, client, secret, screenshot sensible ou infrastructure réelle.
