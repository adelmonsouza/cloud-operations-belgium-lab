# VMware vSphere

## Objectif du module
Comprendre les concepts VMware vSphere utilisés dans les environnements hybrides.

## Pourquoi ce module est important pour Cloud Operations
De nombreuses infrastructures combinent cloud public et virtualisation on-prem. Ce module vise à transformer une connaissance théorique en capacité opérationnelle démontrable.

## Compétences visées
- Comprendre VM, hôte, cluster et datastore.
- Comprendre réseau virtuel et snapshots.
- Identifier risques opérationnels.
- Documenter une architecture hybride.

## Labs prévus
- Lab théorique vSphere.
- Schéma VM/réseau/stockage.
- Analyse de risques snapshots.
