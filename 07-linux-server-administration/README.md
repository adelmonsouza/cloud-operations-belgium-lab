# Administration de serveurs Linux

## Objectif du module
Administrer un serveur Linux pour des besoins d'exploitation cloud et infrastructure.

## Pourquoi ce module est important pour Cloud Operations
Linux est très présent dans les environnements cloud, conteneurs, supervision et automatisation. Ce module vise à transformer une connaissance théorique en capacité opérationnelle démontrable.

## Compétences visées
- Gérer utilisateurs, permissions et services.
- Utiliser systemd et journaux.
- Diagnostiquer disque, CPU, mémoire et réseau.
- Documenter une procédure d'administration.

## Labs prévus
- Inventaire serveur.
- Gestion de service systemd.
- Diagnostic espace disque et logs.

## Preuves attendues
Commandes, sorties anonymisées, notes et runbooks.
