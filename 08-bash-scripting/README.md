# Scripting Bash

## Objectif du module
Automatiser des tâches Linux simples avec Bash de manière lisible et non destructive.

## Pourquoi ce module est important pour Cloud Operations
Bash permet d'automatiser diagnostics, contrôles, rapports et tâches répétitives dans les environnements Linux et cloud. Ce module vise à transformer une connaissance théorique en capacité opérationnelle démontrable.

## Compétences visées
- Ecrire des scripts robustes avec `set -euo pipefail`.
- Valider les entrées.
- Produire des messages clairs.
- Eviter les actions destructives.

## Labs prévus
- Script de vérification système.
- Script de contrôle de fichiers.
- Script de rapport local.

## Preuves attendues
Scripts, tests manuels, sorties anonymisées.
