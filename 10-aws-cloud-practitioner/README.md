# AWS Cloud Practitioner

## Objectif du module
Préparer les concepts fondamentaux AWS Cloud Practitioner.

## Pourquoi ce module est important pour Cloud Operations
Même avec un focus Azure, la culture multi-cloud aide à comprendre services, responsabilités partagées, coûts et sécurité. Ce module vise à transformer une connaissance théorique en capacité opérationnelle démontrable.

## Compétences visées
- Comprendre le modèle cloud AWS.
- Identifier services principaux.
- Expliquer responsabilité partagée.
- Comprendre coûts et support.

## Labs prévus
- Cartographie de services AWS.
- Mini-lab conceptuel IAM.
- Comparaison Azure/AWS.
