# Microsoft 365 Administration

## Objectif du module
Comprendre les bases d'administration Microsoft 365 : utilisateurs, groupes, licences et sécurité.

## Pourquoi ce module est important pour Cloud Operations
Microsoft 365 est souvent lié aux identités, accès et opérations IT quotidiennes. Ce module vise à transformer une connaissance théorique en capacité opérationnelle démontrable.

## Compétences visées
- Comprendre utilisateurs, groupes et licences.
- Documenter des procédures d'administration.
- Identifier les risques de sécurité courants.
- Préparer des checklists de support avancé.

## Labs prévus
- Gestion fictive d'utilisateurs.
- Checklist de sécurité M365.
- Procédure d'arrivée/départ utilisateur.

## Preuves attendues
Procédures, checklists et evidence anonymisée.
